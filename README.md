# KinLore

A private journaling tool that shows you patterns in how you write over time.
Raw journal text is never stored — only computed numeric metrics.

> KinLore is a self-reflection tool, not a medical diagnosis. If you're concerned
> about memory or cognitive changes, please talk to a doctor.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Recharts
- Postgres + auth backend
